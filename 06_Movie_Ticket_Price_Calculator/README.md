# Movie Ticket Price Calculator

## Features

- Customer Name
- Number of Tickets
- Automatic Bill Generation
- 10% Discount for 5 or More Tickets
- Console-Based Application

## Technologies

- Java
- Scanner
- If-Else

## Compile

```bash
javac MovieTicketPriceCalculator.java
```

## Run

```bash
java MovieTicketPriceCalculator
```
