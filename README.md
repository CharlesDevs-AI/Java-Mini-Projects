# ☕ Java Mini Projects

A collection of **10 beginner-friendly Java console applications** built using Core Java. These projects are designed to strengthen programming fundamentals, improve problem-solving skills, and build a strong Java portfolio for students and beginners.

---

## 📂 Projects Included

| No. | Project | Description |
|-----|---------|-------------|
| 01 | 🎲 Dice Roller | Simulates rolling a dice and generates random numbers. |
| 02 | 🏧 ATM Simulator | Perform deposit, withdrawal, balance inquiry, and transaction history. |
| 03 | 📒 Contact Book | Add, search, view, and delete contacts. |
| 04 | 🎓 Student Grade Calculator | Calculates total marks, average, and grade. |
| 05 | 🛒 Shopping Bill Generator | Generates shopping bills with GST calculation. |
| 06 | 🎬 Movie Ticket Price Calculator | Calculates ticket price with discount support. |
| 07 | ❓ Quiz Application | Multiple-choice quiz with automatic score calculation. |
| 08 | ⭕ Tic Tac Toe | Two-player console Tic Tac Toe game. |
| 09 | ⏱ Stopwatch | Measures elapsed time between start and stop. |
| 10 | 🕒 Digital Clock | Displays the current time updating every second. |

## ▶️ Clone Repository

git clone https://github.com/CharlesDevs-AI/Java-Mini-Projects.git
```

```

## ▶️ Compile & Run

Navigate to any project folder.

Example:

```bash
cd 01_Dice_Roller

javac DiceRoller.java

java DiceRoller
```
